# 軟體工程 2021
## Project：冷生
一款學習心理學知識的RPG電腦遊戲


### 介紹
將死的老約翰在病床上拿起了日記本，回想他這一生的經歷，眼角泛著微
微的淚光……
玩家將操作小男孩約翰，並做出會影響他人生的選擇。在約翰小時候，他
撿到一本屬名J的日記本，日記本紀錄了J一生的故事。然而這本日記似乎格
外具有某種神秘力量，就像魔法一般，日記內容與約翰遇到的人生難題竟永遠
有著驚人地相似！


### 主要特色
大量融入心理學與冷知識，玩家在享受劇情的同時，能與約翰一同成長
多樣化的分支劇情，由玩家拼湊出屬於自己的人生故事
選擇沒有絕對的對錯，打破善有善報、惡有惡報的公式設定 
交錯的實與虛，使用劇中劇的手法將約翰的人生與筆記交織在一起，作為
虛構的日記本一點一滴的啟發著約翰，同時約翰也在無形中改變日記內容

### 目標受眾 
對劇情、冒險和益智題材感興趣的休閒遊戲玩家。
根據《遊戲軟體分級管理辦法》分級標準，建議歸類在輔15級。
